🔄 Polymorphic Tool — Walkthrough

Hidden-Bytes Project  |  For non-technical stakeholders  |  Safe educational edition

What this tool does in plain language:
The Polymorphic tool takes a small piece of code (called a payload) that you provide, locks it inside a brand-new program, and wraps that program in a self-changing shell. Every time the generated program runs, it slightly rewrites its own source so its digital fingerprint (SHA-256 hash) changes — but its behavior stays exactly the same. Then it unlocks and runs your payload.

1. What Polymorphism Means Here

Think of it like a person who changes their clothes every day but still does the same job. The file's appearance (hash) changes every run, but the behavior (what it does) never changes.

📝
Same behavior
Prints the same message / runs the same payload every time.
🔄
🆕
Different hash
File's SHA-256 fingerprint changes on every run.

2. How the Tool Builds the Program (Step by Step)

1
Read your payload
You supply a payload file (e.g. a script). It must exist and not be empty.
▶
2
Generate a random key
A fresh 256-bit random AES key is created. No passphrase is needed.
▶
3
Encrypt the payload
Your payload is locked with AES-256-GCM so it can't be read as plain text.
▶
4
Build a self-changing wrapper
A new program is created that carries the locked payload and a signature token.
▶
5
Save the generated program
The output file is written and made executable.

3. What Happens When You Run It

▶
Run
You start the generated program.
🔄
✏
Rewrite itself
It changes its own signature token — hash changes.
🔓
📦
Unlock payload
Decrypts and verifies the embedded payload.
▶
🚀
Run payload
Executes your payload with the arguments you gave.

4. Hash Changes, Output Stays the Same

Run 1 → hash:
a1b2c3d4e5f6...
Run 2 → hash:
z9y8x7w6v5u4...
Run 3 → hash:
m4n5o6p7q8r9...
Output every time: PAYLOAD-RAN (unchanged)

5. Example Commands — Step by Step

Command 1 — Generate a polymorphic program

$ ./polymorphic --generate polymorphic_demo.py --payload message.py
1
Read
Tool reads message.py (your payload).
▶
2
Key
A fresh 256-bit random AES key is generated.
▶
3
Lock
Payload is encrypted with AES-256-GCM.
▶
4
Wrap
A self-changing wrapper program is built around the locked payload.
▶
5
Save
Generated program saved as polymorphic_demo.py.

Command 2 — Watch the hash change, output stay the same

$ sha256sum polymorphic_demo.py
$ python3 polymorphic_demo.py
$ sha256sum polymorphic_demo.py

▶
2

▶
3

Record the fingerprint again — it changed, but output stayed the same.
