04 The four stealth moves

Each maps to a concrete part of the code.

🔒

Encrypt

AES-256-GCM scrambles the file with a fresh random key. Wrong key = fails, loudly.

crypto.build_payload()
📦

Inflate

Random padding grows the file to an exact size. Big, bland files resist inspection.

runner._build_archive() · padding
⏱️

Delay

A pre-execution wait. Many sandboxes time out before it ends and see nothing.

header.delay_seconds · time.sleep
🎁

Self-extract

The key rides inside the opener, so the artifact unlocks and launches itself.

runner.RUNNER_TEMPLATE
Defender's takeaway: size and timing alone can blind signature and sandbox scanners — which is exactly why modern defense watches behaviour at runtime, not just the file.
